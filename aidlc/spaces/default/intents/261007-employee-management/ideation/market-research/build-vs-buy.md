# Build vs. Buy Assessment: Employee Management Web Application

## Strategic Context

To replace error-prone spreadsheets and manual tracking workflows, the organization evaluated three primary options: purchasing off-the-shelf commercial SaaS (e.g., BambooHR + Jira), stitching open-source tools, or building a bespoke, tailored web application [Q1] [Q3].

## Comparison Matrix

| Evaluation Dimension | Commercial SaaS Multi-Tool (Buy) | Open-Source Tool Stitching (Assemble) | Custom Web Application (Build) | Strategic Assessment | Source |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Feature Fit** | Partial (requires combining separate HR and project management tools; complex integrations) | Fragmented (mismatched schemas between employee directory and task boards) | **Exact Match**: Purpose-built for profiles, multi-team assignments, 3-stage tasks, and company dashboard | Custom build delivers 100% feature alignment with zero bloat [desc] [Q3] | [desc] [Q3] |
| **Total Cost of Ownership (TCO)** | High recurring monthly per-seat licensing fees ($15-$40/user/month across HR + task tools) | Variable (hosting, maintenance, plugin compatibility overhead) | **Low Recurring Cost**: Standard hosting infrastructure with zero per-user SaaS license fees | Custom build eliminates recurring per-seat subscription overhead [Q3] | [Q3] |

| **Extensibility & UX Control** | Rigid vendor roadmaps, limited workflow customization | Complex plugin ecosystems | **Maximum Agility**: Direct code ownership allowing rapid feature iterations and aesthetic excellence | Full UX flexibility for future enhancements [Q3] [Q4] | [Q3] [Q4] |
| **Time to Value** | Fast initial onboarding, but long workflow tailoring time | Medium | Rapid greenfield delivery through structured AI-DLC lifecycle | Fast delivery with high precision [Q3] [scope] | [Q3] [scope] |

## Recommendation & Calculus

- **Decision**: **Build Custom Web Application** [Q3].
- **Rationale**: 
  1. Building custom ensures direct support for specific core features (employee profile pictures, age, positions, multi-team membership, 3-stage tasks, and company data dashboard) without forcing users to navigate disjointed third-party interfaces [desc] [Q2].
  2. Eliminates recurring SaaS licensing expenses for small-to-mid sized teams (10-250 users) [Q3] [Q5].
  3. Provides an extensible architectural baseline for company-wide expansion [Q3].
